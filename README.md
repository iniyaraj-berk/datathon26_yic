# datathon26_yic
## Interactive Tableau dashboard

[Explore advertised benefits in California job ads](https://public.tableau.com/app/profile/celine.tan7285/viz/YIC_Datathon2026/Dashboard)

Compares advertised benefits in about 39,000 hourly Indeed job postings, grouped into $5 pay bands so full-time and part-time jobs are matched by pay.

[An in-depth look](https://public.tableau.com/app/profile/yana.sen1982/viz/ThePart-TimePenalty/Dashboard1)

This dashboard breaks down more in about 64,000 Indeed postings that list at least one benefit. Full-time ads list every core benefit more often (for example, health insurance 82% vs 49%), and the gap grows as pay rises and is largest in Education.
